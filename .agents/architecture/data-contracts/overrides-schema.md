# Спецификация контракта: overrides.json

Файл `overrides.json` содержит массив ручных корректировок расписания (отмены пар, переносы, замены аудиторий и предметов). Корректировки накладываются скриптом `parser.py` и генерируются ботом `bot.py` через Gemini API.

---

## 1. Схема JSON (JSON Schema)

```json
[
  {
    "id": "ov-20261014-math-lek",
    "date": "2026-10-14",
    "action": "set",
    "time_start": "10:40",
    "type": "ЛЕК",
    "subject": "Математика",
    "location": null,
    "keep_original_location": true,
    "comment": "Замена: вместо практики лекция по математике (аудитории по расписанию)"
  }
]
```

## 2. Описание полей

| Поле | Тип | Обязательное | Допустимые значения / Описание |
|:-----|:----|:-------------|:-------------------------------|
| `id` | String | Да | Уникальный идентификатор формата `ov-<YYYYMMDD>-<slug>` |
| `date` | String | Да | Дата в формате `YYYY-MM-DD` |
| `action` | String | Да | `"set"` (замена/добавление) или `"cancel"` (отмена пары) |
| `time_start` | String / Null | Нет | Время начала пары (`"HH:MM"`, например `"08:50"`, `"10:40"`). Если `null` при `cancel`, отменяются все пары предмета за день. |
| `type` | String | Да | `"ЛЕК"` (лекция), `"ПРАК"` (практика), `"ЛАБ"` (лабораторная) |
| `subject` | String | Да | Название предмета (например `"Математика"`, `"Дискретка"`) |
| `location` | String / Null | Нет | Номер аудитории/корпуса или `null` |
| `keep_original_location`| Boolean | Да | Сохранять ли аудиторию из исходного расписания, если `location` не указан |
| `comment` | String | Да | Человекочитаемое пояснение причины правки |

---

## 3. Правила валидации
* Любой агент, вносящий изменения в `overrides.json`, обязан сохранять валидный JSON и сортировку записей по полю `date`.
* Запрещено удалять исторические оверрайды без явного указания пользователя.
