# Спецификация контракта: schedule.json <-> ScheduleModels.kt

Данный контракт связывает генератор расписания на Python (`parser.py`) и модель десериализации в Android-клиенте ([`ScheduleModels.kt`](file:///c:/Users/Nikita/Documents/GitHub/tusur-schedule/android/app/src/main/java/ru/lican1907/tusurschedule/data/ScheduleModels.kt)).

---

## 1. Схема верхнего уровня (`ScheduleResponse`)

```json
{
  "generated_at": "2026-10-18T01:30:00+07:00",
  "group": "426top-4",
  "pe_teachers": ["Тарасов А.В.", "Иванов И.И."],
  "english_teachers": ["Ёлкина Д.М.", "Петрова П.П."],
  "subgroups": ["1", "2"],
  "days": [ ... ]
}
```

* `subgroups`: список уникальных обнаруженных подгрупп в расписании группы (например, `["1", "2"]` или `["подгруппа а", "подгруппа б"]`). По умолчанию `[]`.

## 2. Схема дня (`DaySchedule`)

```json
{
  "date": "2026-10-19",
  "weekday": 1,
  "beer_time": "14:15",
  "lessons": [ ... ]
}
```

* `weekday`: целое число от 1 (понедельник) до 7 (воскресенье).
* `beer_time`: время окончания последней пары дня.

## 3. Схема занятия (`LessonItem`)

```json
{
  "uid": "20261019-1040-math-lek",
  "date": "2026-10-19",
  "time_start": "10:40",
  "time_end": "12:15",
  "is_shifted_time": false,
  "type": "ЛЕК",
  "subject": "Математика",
  "subject_short": "Матем.",
  "subject_full": "Высшая математика",
  "location": "315 ГК",
  "teacher": "Прокопьев А.А.",
  "subgroup": "1",
  "color_hex": "#2EA043",
  "color_id": "10",
  "is_override": false,
  "is_cancelled": false,
  "override_comment": null,
  "pe_rooms": {
    "Тарасов А.В.": "Спорткомплекс зал 1"
  },
  "english_rooms": {
    "Ёлкина Д.М.": "ауд. 412"
  }
}
```

* `subgroup`: строковый идентификатор подгруппы (например, `"1"`, `"2"`, `"подгруппа а"`, `"подгруппа б"`). Если занятие общее для всего потока/группы (лекции, общие практики), поле равно `null` или пустой строке `""`.

---

## 4. Семантика и нормализация фильтрации подгрупп

1. **Общие занятия**: если у занятия `subgroup == null` или `subgroup == ""`, оно считается общим для всей академической группы и **отображается всегда**, независимо от выбранного фильтра подгруппы.
2. **Правило нормализации**: сопоставление подгруппы пользователя и занятия производится без учета регистра и служебных слов (`"подгруппа"`, `"п/г"`, `"пг"`):
   - `"подгруппа 1"` $\rightarrow$ `"1"`
   - `"1 подгруппа"` $\rightarrow$ `"1"`
   - `"подгруппа а"` $\rightarrow$ `"а"`
3. **Режим «Все подгруппы» (`ALL`)**: отключение фильтрации, отображаются занятия всех подгрупп одновременно.

---

## 5. Инварианты совместимости
* Android использует `kotlinx.serialization` с флагом `ignoreUnknownKeys = true`, однако **удаление существующих полей или изменение типов данных ломает старые версии установленного приложения**.
* Поле `subgroup` в Kotlin-модели `LessonItem` строго объявляется с дефолтным значением: `val subgroup: String? = null`.
* Поле `subgroups` в Kotlin-модели `ScheduleResponse` строго объявляется с дефолтным значением: `val subgroups: List<String> = emptyList()`.
* Поле `color_id` строго соответствует идентификаторам цветовой палитры Google Calendar API (`"1"` .. `"11"`).
