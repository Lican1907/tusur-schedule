# Задача TS-004: Фильтрация подгрупп в Glance-виджете рабочего стола

> **ID**: `TS-004`  
> **Название**: Интеграция фильтрации подгрупп в ScheduleWidget (Hero-карточка, списки, бейджи)  
> **Домен**: `Android / Glance Widget`  
> **Исполнитель**: `Contractor-Android`  
> **Статус**: `Done`  

---

## 1. Цель
Обеспечить корректную фильтрацию занятий по выбранной подгруппе в виджете рабочего стола (`ScheduleWidget.kt`), включая расчёт текущей и следующей пары в Hero-карточке, фильтрацию списка занятий и отображение индикатора подгруппы в шапке виджета.

---

## 2. Архитектурный контекст
Виджет рабочего стола на Jetpack Glance рассчитывает Hero-карточку (`HeroInfo`) на основе списка занятий на текущий и последующие дни. Если студент учится в 1-й подгруппе, а в расписании стоит лабораторная работа 2-й подгруппы:
1. Без фильтрации Hero-карточка будет ошибочно сообщать о начале пары или вести обратный отсчет до чужого занятия.
2. В общем списке виджета будут выводиться чужие пары.
3. Время окончания пар дня (Beer Time) будет рассчитываться неверно.

---

## 3. Требования к реализации

### 3.1. Фильтрация входного списка занятий в `ScheduleWidget.provideGlance`
- Получать выбранную пользователем подгруппу:
  ```kotlin
  val selectedSubgroup = repo.selectedSubgroup
  ```
- Фильтровать `todayRawLessons` перед передачей в `consolidateLessons()` и `computeHeroInfo()`:
  ```kotlin
  val filteredTodayRaw = todayRawLessons.filter { it.matchesSubgroup(selectedSubgroup) }
  val todayMerged = consolidateLessons(filteredTodayRaw)
  ```
- Аналогично фильтровать список занятий для предстоящих дней `upcomingDays`:
  ```kotlin
  val filteredUpcomingLessons = day.lessons.filter { it.matchesSubgroup(selectedSubgroup) }
  val dayMerged = consolidateLessons(filteredUpcomingLessons)
  ```

### 3.2. Расчет Beer Time и Hero-карточки
- Расчет Beer Time и поиск следующей пары в `computeHeroInfo()` должны учитывать только отфильтрованные занятия (чтобы время отдыха и обратный отсчет соответствовали фактическому расписанию студента).

### 3.3. Индикатор подгруппы в шапке виджета
- В шапке виджета (`WidgetHeader`):
  - Если `selectedSubgroup != "ALL"`, отображать подгруппу рядом с названием группы в чипе: например, `"$groupName · п/г $subgroupDisplay"` (где `$subgroupDisplay` — нормализованное имя, например `"1"` или `"2"`).
  - Если `selectedSubgroup == "ALL"`, отображать стандартное имя группы без префиксов.

### 3.4. Ограничения Glance
- Строго соблюдать требования скилла `android-glance-widget`:
  - Использовать только поддерживаемые Glance-компоненты (`Row`, `Column`, `Box`, `Text`, `LazyColumn`, `ImageProvider`).
  - Никаких тяжелых вычислений или сетевых запросов в UI-потоке виджета.
