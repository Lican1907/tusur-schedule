# Мета-скилл создания скиллов в tusur-schedule

Скилл регламентирует добавление новых знаний в `.agents/skills/<skill-name>/SKILL.md` для ускорения агентов-подрядчиков.

---

## 1. Сигналы для создания скилла в проекте tusur-schedule
1. **Специфика Android Jetpack Glance**: если агент пытается использовать стандартные модификаторы Compose (например, `clickable` вместо `actionRunCallback` или сложные canvas-анимации), которые не поддерживаются в Glance.
2. **Ошибки структуры TUSUR**: если сайт ТУСУРа изменил верстку или в HTML появились аномалии (новые типы занятий, пустые аудитории, смещенные пары).
3. **Промпты Gemini**: если бот некорректно парсит сообщения преподавателей со сложными датами ("в следующий вторник вместо пятницы").

---

## 2. Формат создания скилла
Каждый скилл размещается в `.agents/skills/<name>/SKILL.md`:
* **YAML Frontmatter**: обязательные поля `name` и емкое `description` от третьего лица.
* **Быстрый старт (Cheat Sheet)**: 2-3 готовых сниппета для копирования.
* **Что делать ЗАПРЕЩЕНО (Anti-patterns)**: перечисление конкретных ошибок.
* **Команда самопроверки**: точная консольная команда проверки без сети.
