# 📅 Автоматическое расписание ТУСУР с прямой синхронизацией Google Календаря

> Автоматизированный сервис парсинга актуального расписания занятий групп Факультета систем управления (ФСУ) ТУСУР: **426топ-4**, **426топ-1**, **426топ-2** и **426-3**. Поддерживает прямую синхронизацию через **Google Calendar API** (для 426топ-4) с нативным окрашиванием плашек (`colorId`), генерацию iCalendar (`.ics`) для GitHub Pages, интерактивный веб-сайт с выпадающим списком выбора группы, систему ручных правок от преподавателей (`overrides.json`) и Telegram-бота (`bot.py`) с распознаванием сообщений через **Gemini API**.

## 🎨 Отображение в виджете и цвета Google Календаря

### 1. Формат заголовков (`SUMMARY`)
В заголовках пар используются аккуратные цветные маркеры после типа пары:
- Обычные пары: `ЛЕК 🟢 Математика`, `ПРАК 🔵 Физ-ра`, `ЛАБ 🟣 Информатика`, `СРС ⚪ ПИТР`, `КУРС 🌸 ...`, `ЗАЧ 🟡 ...`, `ЭКЗ 🔴 ...`
- Изменённые/добавленные преподавателем: `⚡ ЛЕК 🟢 Математика`, `⚡ ЛЕК 🟢 Дискретка`
- Отменённые пары: `❌ [ОТМЕНА] <Предмет с заглавной буквы>` (например, `❌ [ОТМЕНА] Дискретка`)
- Событие отдыха: `🍺 Можно пить пиво!`

### 2. Нативная цветовая палитра Google Calendar API (`colorId`)
Цвет события задается на уровне самого Google Календаря (окрашивается вся карточка события):

| Тип / Статус | `colorId` | Название палитры Google | Цвет карточки |
| :--- | :---: | :--- | :--- |
| **ЛЕК** (Лекция) | `"10"` | Basil | 🟩 Зелёный |
| **ПРАК** (Практика) | `"9"` | Blueberry | 🟦 Синий |
| **ЛАБ** (Лабораторная) | `"3"` | Grape | 🟪 Фиолетовый |
| **СРС** (Самостоятельная) | `"8"` | Graphite | ⬜ Графитовый / Темно-серый |
| **КУРС** (Курсовой проект) | `"4"` | Flamingo | 🌸 Розовый |
| **ЗАЧ** (Зачёт / Диф. зачёт) | `"5"` | Banana | 🟨 Жёлтый |
| **ЭКЗ** (Экзамен) | `"11"` | Tomato | 🟥 Красный |
| **ОТМЕНА** (`❌ [ОТМЕНА] ...`) | `"8"` | Graphite | ⬜ Графитовый (приглушает отменённую пару) |
| **ПИВО** (`🍺 Можно пить пиво!`) | `"5"` | Banana | 🟨 Золотисто-янтарный |

### 3. Локации и корпуса (`LOCATION`)
Место проведения визуально выделяется пином `📍 <КОРПУС> <АУДИТОРИЯ>`, что отделяет аудиторию от времени начала пары во второй строке мобильного виджета:
- **ГК** — Главный корпус (пр. Ленина, 40)
- **РК** — Радиотехнический корпус (ул. Вершинина, 47)
- **ФЭТ** — Корпус ФЭТ (ул. Вершинина, 74 / ул. Красноармейская, 146)

Примеры: `📍 РК 310`, `📍 ГК 411`, `📍 ФЭТ 412` (для предмета «Физ-ра»: для группы 426топ-4 автоматически подставляется аудитория преподавателя Тарасова А.В. на соответствующую дату, например `📍 Г\Б`, `📍 ауд. 21`; для остальных групп или дат без расписания: `📍 см. описание`).

## 📝 Система ручных правок (`overrides.json`)

Файл `overrides.json` в корне репозитория позволяет переопределять расписание (добавлять замены, отменять пары или изменять аудитории):

```json
[
  {
    "id": "override-20261014-1040-set",
    "date": "2026-10-14",
    "action": "set",
    "time_start": "10:40",
    "type": "ЛЕК",
    "subject": "Математика",
    "location": null,
    "keep_original_location": true,
    "comment": "Замена: ЛЕК Математика вместо пары по расписанию"
  },
  {
    "id": "override-20261014-cancel-diskretka",
    "date": "2026-10-14",
    "action": "cancel",
    "time_start": null,
    "type": "ПРАК",
    "subject": "Дискретка",
    "location": null,
    "keep_original_location": true,
    "comment": "Отмена практического занятия по Дискретке"
  }
]
```

### Логика применения правок в `parser.py`:
1. **Отмена занятия (`action: "cancel"`):**
   - Поиск пары по дате + предмету (регистронезависимо) + типу (и времени начала, если передано).
   - Событие **не удаляется**, а переименовывается строго в `❌ [ОТМЕНА] <Предмет с заглавной буквы>`.
   - Исходные время и `LOCATION` сохраняются (в виджете видно `❌ [ОТМЕНА] Дискретка`, строка ниже: `15:00, ФЭТ 418`).
   - Назначается `colorId: "8"` (серый графит).
   - В начало `DESCRIPTION` добавляется комментарий преподавателя: `❌ Занятие отменено преподавателем: <comment>`.
   - **Важно:** Отменённые пары исключаются из расчёта времени начала пива! Если отменили последнюю пару дня, событие `🍺 Можно пить пиво!` автоматически сдвигается на момент окончания предыдущей активной пары.
2. **Замена / добавление занятия (`action: "set"`):**
   - Если пара уже есть на этот слот и указан `keep_original_location: true`, её аудитория сохраняется.
   - Заголовок получает префикс `⚡`: `⚡ ЛЕК 🟢 Математика`.
   - Назначается `colorId` соответствующего типа занятия (например, `"10"` для лекций).
   - В начало `DESCRIPTION` добавляется: `⚡ Изменение в расписании от преподавателя: <comment>`.

## 🤖 Telegram-бот (`bot.py`) с Gemini AI

Бот предназначен для мгновенной обработки текстовых и пересланных сообщений от преподавателей или старосты.

### Ключевые возможности:
- **Строгая авторизация:** Доступ открыт исключительно доверенным администраторам (`@nktatm` по умолчанию, настраивается через `ALLOWED_USERNAMES`). Неавторизованным пользователям доступ блокируется.
- **Интеллектуальный парсинг через Gemini API (`google-genai`):** Модель `gemini-2.5-flash` со структурированным выводом (Structured Outputs) распознает:
  * Относительные даты («завтра», «в этот четверг», «15 октября»).
  * Специфику ТУСУР (сетку звонков, сокращения предметов: Дискретка, ОРГ, ПИТР).
  * Фразы вроде «аудитории по расписанию» (`keep_original_location: true`).
  * Фильтрует посторонний текст (результаты контрольных, дедлайны).
- **Интерактивное подтверждение:** Перед записью бот присылает карточку предпросмотра с цветовыми индикаторами плашек и кнопками:
  * `[✅ Применить в Google Calendar]` — сохраняет правки в `overrides.json`, коммитит их через GitHub API в ветку `main` (при наличии `GITHUB_TOKEN`) и сразу же вызывает `gcal_sync.py` для пуша в Google Календарь.
  * `[❌ Отмена]` — отменяет операцию.

## 🔄 Прямая синхронизация Google Calendar API (`gcal_sync.py`)

Модуль `gcal_sync.py` обеспечивает идемпотентный upsert событий в целевой Google Календарь:
- **Аутентификация:** Сервисный аккаунт Google Cloud через переменную окружения `GOOGLE_CREDENTIALS_JSON` (строка JSON) или локальный файл `service_account.json`.
- **Идемпотентность:** События идентифицируются по `iCalUID` и `extendedProperties.private.tusur_uid`. При повторном запуске события обновляются, а не дублируются.
- **Цвета и уведомления:** Проставляются `colorId` карточек и персональное всплывающее уведомление (popup за 0 минут) для события `🍺 Можно пить пиво!`.

## 📱 JSON API для виджета расписания

Вместе с календарями `.ics`, пайплайн генерирует JSON-файлы, готовые для использования мобильным виджетом и веб-приложениями:

1. **`today.json`** (и `today-<group>.json`):
   - Содержит нормализованный список пар на текущий день (`pair_num`, `time_start`, `time_end`, `subject`, `lesson_type`, `teacher`, `room`, `building`, `status`, `color_id`).
   - Содержит статус текущей пары в реальном времени (`pair_status`: `in_pair`, `in_break`, `before_classes`, `after_classes`), текущую пару (`current_pair`), следующую пару (`next_pair`), а также количество минут до конца пары или перерыва (`minutes_left_in_pair`, `minutes_until_next_pair`).
   - Содержит блок события отдыха `beer_event` (если сегодня есть/были пары).

2. **`schedule-<group>.json`** (и `schedule.json` для группы по умолчанию):
   - Полное структурированное расписание семестра, сгруппированное по датам (`days: { "YYYY-MM-DD": [...] }`).

## 🍺 Событие отдыха «Можно пить пиво!»

- Создаётся **строго один раз** и только для текущего дня (`target_date == today` в часовом поясе `Asia/Tomsk`).
- Назначается сразу после окончания последней **активной** пары текущего дня (отменённые через `overrides.json` пары игнорируются).
- Заголовок: `🍺 Можно пить пиво!`, локация: `🎉 Свобода`, длительность: 2 часа, `colorId: "5"`.
- Содержит мгновенное напоминание (`VALARM` / popup в момент старта).

## 🛠 Настройка и запуск

### 1. Переменные окружения (`.env`)
Создайте файл `.env` в корневой директории:
```env
# Google Calendar API
GOOGLE_CALENDAR_ID=your_calendar_id@group.calendar.google.com
GOOGLE_APPLICATION_CREDENTIALS=service_account.json
# Или JSON строкой (для GitHub Actions Secrets):
# GOOGLE_CREDENTIALS_JSON={"type": "service_account", ...}

# Telegram Bot & Gemini
TELEGRAM_BOT_TOKEN=123456789:ABCdefGHI...
GEMINI_API_KEY=AIzaSy...
ALLOWED_USERNAMES=nktatm
GITHUB_TOKEN=ghp_...
```

### 2. Установка зависимостей
```bash
python -m venv .venv
# Активация:
# Windows (PowerShell): .venv\Scripts\Activate.ps1
# Linux / macOS: source .venv/bin/activate

pip install -r requirements.txt
```

### 3. Запуск парсера и синхронизации
```bash
# Парсинг текущей недели:
python parser.py

# Полный парсинг всех недель семестра:
python parser.py --all-weeks

# Ручная прямая синхронизация с Google Calendar:
python gcal_sync.py
```

### 4. Запуск Telegram-бота
```bash
python bot.py
```

### 5. Запуск модульных тестов
```bash
python -m unittest discover tests
```

## 🤖 CI/CD и автоматизация GitHub Actions

- **Расписание Cron:** Запуск каждый день в **15:00 UTC** (`0 15 * * *`, 22:00 по томскому времени UTC+7).
- **Секреты репозитория:** В GitHub Actions проброшены секреты `GOOGLE_CREDENTIALS_JSON` и `GOOGLE_CALENDAR_ID`.
- **Изолированный деплой:** Файл `schedule.ics` и `index.html` автоматически публикуются в ветку `gh-pages` для подписчиков календаря без засорения ветки `main`.
