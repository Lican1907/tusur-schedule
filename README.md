# 📅 Автоматическое расписание ТУСУР в формате iCalendar (.ics)

> Автоматический парсер актуального расписания занятий группы **426топ-4** (Факультет систем управления, ТУСУР) в стандартный формат **iCalendar (.ics)** с ежедневным автообновлением через **GitHub Actions** и публикацией на **GitHub Pages**.

## 📲 Как подключить календарь

### Apple Calendar (iPhone / iPad / Mac)
1. Нажмите на [странице проекта](https://lican1907.github.io/tusur-schedule/) кнопку **«Подписаться в Apple Calendar»** (ссылка `webcal://`).
2. Либо перейдите в **Настройки → Календарь → Учётные записи → Новая учётная запись → Подписные календари**.
3. Вставьте ссылку: `https://lican1907.github.io/tusur-schedule/schedule.ics`
4. Нажмите «Далее» и сохраните. Календарь будет синхронизироваться автоматически.

### Google Календарь (Android / ПК)
1. Откройте веб-версию [Google Календаря](https://calendar.google.com/).
2. В левой колонке найдите раздел **«Другие календари»** и нажмите **«+» → «С URL-адреса»**.
3. Вставьте ссылку `https://lican1907.github.io/tusur-schedule/schedule.ics` и нажмите **«Добавить календарь»**.

### Яндекс.Календарь
1. Перейдите в настройки [Яндекс.Календаря](https://calendar.yandex.ru/).
2. Выберите **«Импорт» → «Подписка на календарь»**.
3. Вставьте ссылку и сохраните.

## ✨ Возможности и особенности

- **Точный часовой пояс:** `Asia/Tomsk` (UTC+7) с корректным блоком `VTIMEZONE` (RFC 5545).
- **Сетка звонков ТУСУРа:**
  - 1 пара: 08:50 – 10:25
  - 2 пара: 10:40 – 12:15
  - 3 пара: 13:15 – 14:50
  - 4 пара: 15:00 – 16:35
  - 5 пара: 16:45 – 18:20
  - 6 пара: 18:30 – 20:05
  - 7 пара: 20:15 – 21:50
- **Полная детализация каждого события:**
  - `SUMMARY`: Полное наименование дисциплины и тип (например, *«Математика (Самостоятельная работа)»*, *«Основы российской государственности (Практика)»*).
  - `LOCATION`: Точный корпус, улица и аудитория (например, *«Радиотехнический корпус, ул. Вершинина, 47, ауд. 310»*).
  - `DESCRIPTION`: Преподаватель (ФИО), подгруппа/примечание, корпус, совместные группы и ссылки на учебные материалы.
  - `UID`: Уникальный детерминированный идентификатор занятия, предотвращающий дублирование при обновлениях.
- **Парсинг всего семестра:** Автоматический обход всех 23 недель семестра с бережными паузами между запросами и агрегацией в единый календарь.
- **CI/CD Автообновление:** GitHub Actions запускается каждую ночь по расписанию (`0 21 * * *` UTC, что соответствует 04:00 по Томску) с флагом `--all-weeks`, обновляя расписание на весь семестр, а также поддерживает ручной перезапуск через `workflow_dispatch`.

## 🛠 Локальный запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Lican1907/tusur-schedule.git
   cd tusur-schedule
   ```

2. Создайте и активируйте виртуальное окружение:
   ```bash
   python -m venv .venv
   # Windows:
   .venv\Scripts\activate
   # Linux/macOS:
   source .venv/bin/activate
   ```

3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

4. Запустите парсер:
   ```bash
   # Парсинг текущей учебной недели:
   python parser.py

   # Или парсинг всех недель семестра:
   python parser.py --all-weeks
   ```

После выполнения файл `schedule.ics` будет сформирован в корне проекта.

## ⚙️ Настройка GitHub Pages в репозитории

Чтобы ссылка на календарь заработала:

1. Откройте ваш репозиторий на GitHub: `https://github.com/Lican1907/tusur-schedule`.
2. Перейдите во вкладку **Settings** (Настройки).
3. В левом боковом меню выберите раздел **Pages** (в блоке *Code and automation*).
4. В поле **Build and deployment → Source** выберите **Deploy from a branch**.
5. В поле **Branch** выберите ветку `gh-pages` и папку `/(root)`.
6. Нажмите **Save**.

Через 1-2 минуты GitHub Pages опубликует ваш календарь по адресу `https://lican1907.github.io/tusur-schedule/schedule.ics`.
