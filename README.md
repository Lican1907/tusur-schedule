## 📲 Как подключить календарь

### Apple Calendar (iPhone / iPad / Mac)
1. Нажмите на [веб-странице](https://lican1907.github.io/tusur-schedule/) кнопку **«Подписаться в Apple Calendar»** (протокол `webcal://`).
2. Либо перейдите в **Настройки → Календарь → Учётные записи → Новая учётная запись → Подписные календари**.
3. Вставьте ссылку: `https://lican1907.github.io/tusur-schedule/schedule.ics`.
4. Сохраните подписку. Календарь будет синхронизироваться автоматически в фоновом режиме.

### Google Календарь (Android / ПК)
1. Откройте веб-версию [Google Календаря](https://calendar.google.com/).
2. В левой колонке в блоке **«Другие календари»** нажмите **«+» → «С URL-адреса»**.
3. Вставьте ссылку `https://lican1907.github.io/tusur-schedule/schedule.ics` и нажмите **«Добавить календарь»**.

### Яндекс.Календарь
1. Перейдите в настройки [Яндекс.Календаря](https://calendar.yandex.ru/).
2. Выберите раздел **«Импорт» → «Подписка на календарь»**.
3. Вставьте ссылку на `.ics` и сохраните.

## 🏗 Архитектура проекта

Репозиторий спроектирован по модульным принципам с разделением исходного кода и генерируемых артефактов:

```
tusur-schedule/
├── .github/
│   └── workflows/
│       └── update.yml      # CI/CD автоматизация (парсинг + деплой в gh-pages)
├── .gitignore              # Исключение артефактов (schedule.ics) и кеша
├── parser.py               # Модульный парсер расписания с типизацией и логированием
├── index.html              # Веб-лендинг для подписки и быстрого копирования URL
├── requirements.txt        # Минимальный набор зависимостей (requests, bs4, icalendar, tzdata)
└── README.md               # Документация проекта
```

### Основные компоненты `parser.py`:
- **Конфигурация и константы:** сетка звонков (`BELL_SCHEDULE`), маркеры занятий (`TYPE_MAPPING`), сокращения дисциплин (`SUBJECT_SHORT_NAMES`), корпусов (`LOCATION_MAPPING`) и часовой пояс `ZoneInfo("Asia/Tomsk")`.
- `fetch_page(url)`: HTTP-клиент с обработкой сетевых сбоев, таймаутами и стратегией автоматических повторов (Exponential Backoff).
- `parse_cell(cell)`: извлечение данных отдельного слота расписания, включая дисциплину, тип, преподавателя, аудиторию, примечания подгрупп и детекцию временных сдвигов.
- `format_event_data(...)`: форматирование компактного заголовка `SUMMARY` через среднюю точку (`🟢 ЛЕК • Математика`) и строки `LOCATION` с префикс-пином (`📍 РК 310`).
- `build_beer_event(...)`: создание VEVENT отдыха «🍺 Можно пить пиво!» строго для текущего дня (`today`), если сегодня проводились пары.
- `parse_semester(all_weeks=True)`: обход карусели недель семестра, агрегация всех занятий, дедупликация событий по UID и генерация валидного RFC 5545 календаря.

## 🎨 Формат сокращений и маркеры

### 1. Типы занятий (`SUMMARY`)
Каждому типу занятия присваивается компактный цветной эмодзи-маркер без скобок:
- 🟢 `ЛЕК` — Лекция
- 🔵 `ПРАК` — Практика
- 🟣 `ЛАБ` — Лабораторная работа
- ⚪ `СРС` — Самостоятельная работа
- 🌸 `КУРС` — Курсовое проектирование
- 🟡 `ЗАЧ` — Зачёт / Диф. зачёт
- 🔴 `ЭКЗ` — Экзамен

### 2. Сокращения дисциплин
- *Дискретная математика* ➔ **дискретка**
- *Основы российской государственности* ➔ **ОРГ**
- *Проектирование индивидуальной траектории развития* ➔ **ПИТР**
- *Иностранный язык* ➔ **английский**
- *Физическая культура и спорт* ➔ **физ-ра**
- *История России* ➔ **история**

Пример `SUMMARY`: `🟢 ЛЕК • дискретка`, `🔵 ПРАК • ОРГ`, `🟣 ЛАБ • ПИТР`.

### 3. Локации и корпуса (`LOCATION`)
Место проведения визуально выделяется пином `📍 <КОРПУС> <АУДИТОРИЯ>`, что отделяет аудиторию от времени начала пары во второй строке мобильного виджета:
- **ГК** — Главный корпус (пр. Ленина, 40)
- **РК** — Радиотехнический корпус (ул. Вершинина, 47)
- **ФЭТ** — Корпус ФЭТ (ул. Вершинина, 74 / ул. Красноармейская, 146)

Примеры: `📍 РК 310`, `📍 ГК 411`, `📍 ФЭТ 412` (если локация не указана, пин опускается).

## ⏱ Сетка звонков и субботнее смещение 12:30

### Стандартная сетка пар ТУСУР:
| Пара | Время |
| :---: | :---: |
| 1 | 08:50 – 10:25 |
| 2 | 10:40 – 12:15 |
| 3 | 13:15 – 14:50 |
| 4 | 15:00 – 16:35 |
| 5 | 16:45 – 18:20 |
| 6 | 18:30 – 20:05 |
| 7 | 20:15 – 21:50 |

### Логика субботних пар «с 12:30»:
По субботам для 3-й пары парсер автоматически определяет смещение («с 12:30»). При обнаружении этой отметки длительность пары устанавливается строго на интервал **12:30 – 14:05** (стандартные 95 минут занятия без обеденного перерыва).

## 🍺 Событие отдыха «Можно пить пиво!»

- Создаётся **строго один раз** и только для текущего дня (`target_date == today` в часовом поясе `Asia/Tomsk`).
- Назначается сразу после окончания последней пары текущего дня.
- Заголовок события: `🍺 Можно пить пиво!`.
- Длительность события: 2 часа.
- Место проведения: `🎉 Свобода`.
- Содержит встроенное напоминание `VALARM` (срабатывание ровно в момент наступления события).
- Если в текущий день занятий нет или сегодня воскресенье, событие не генерируется.

## 🛠 Локальный запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Lican1907/tusur-schedule.git
   cd tusur-schedule
   ```

2. Создайте и активируйте виртуальное окружение:
   ```bash
   python -m venv .venv

   # Windows (PowerShell):
   .venv\Scripts\Activate.ps1

   # Linux / macOS:
   source .venv/bin/activate
   ```

3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

4. Запустите парсер:
   ```bash
   # Парсинг текущей учебной недели:
   python parser.py

   # Полный парсинг всех недель семестра:
   python parser.py --all-weeks
   ```

Сгенерированный файл `schedule.ics` будет сохранён в корневой директории (и автоматически игнорируется Git).

## 🤖 CI/CD и GitHub Pages

- **Расписание Cron:** Пайплайн запускается автоматически каждый день в **21:00 UTC** (`0 21 * * *`), что соответствует **04:00 по томскому времени (UTC+7)**.
- **Ручной запуск:** Доступен запуск через `workflow_dispatch` во вкладке Actions.
- **Чистый Git flow:** Ветка `main` содержит исключительно исходный код. Генерируемый календарь `schedule.ics` и веб-страница `index.html` деплоятся изолированно в служебную ветку **`gh-pages`** экшеном `JamesIves/github-pages-deploy-action@v4`, полностью предотвращая конфликты слияния и засорение истории коммитов.
