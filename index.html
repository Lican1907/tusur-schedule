Приложение Google Календарь не умеет подписываться по ссылке. Откройте эту страницу в Safari или Chrome (не во встроенном браузере мессенджера) и включите версию для компьютера: Safari — «аА» → «Запрос настольного веб-сайта», Chrome на iPhone — «...» → «Запросить полную версию», Chrome на Android — «⋮» → «Версия для ПК». Затем нажмите кнопку Google ещё раз — живой календарь сразу появится в приложении (если скрыт, включите его в боковом меню и настройках синхронизации приложения).

Как подключить подписку:

  1. iPhone / iPad / Mac: Выберите нужную группу выше и нажмите «Подписаться в Apple Calendar» или откройте Настройки → Календарь → Учётные записи → Новая учётная запись → Подписные календари и вставьте ссылку.
  2. Google Календарь: Выберите группу выше и нажмите кнопку «Добавить в Google Календарь» (для группы 426топ-4 подключает прямой календарь без задержки обновлений; для остальных групп — стандартную подписку по URL). На телефоне приложение так не умеет: откройте страницу в Safari или Chrome в режиме «Запрос настольного веб-сайта» («Версия для ПК») и нажмите кнопку ещё раз. Либо на компьютере перейдите на calendar.google.com → «+» рядом с «Другие календари» → «Добавить по URL» и вставьте ссылку.
  3. Яндекс.Календарь: Откройте Настройки календаря → «Импорт» → «Подписка на календарь» → вставьте скопированную ссылку на .ics.
